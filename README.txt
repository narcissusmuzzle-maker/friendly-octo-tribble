U613 «Циферблат» для Amazfit Bip Max — версия 0.1.11 (две верхние полоски берут цвета из приложения U613 Stat; нажатие на них — быстрое обновление)

ЧТО ЭТО
Отдельный проект (циферблат, не приложение). Чёрный экран без часов.
  Сверху — две тонкие полоски статистики без подписей, у каждой три сегмента: месяц / неделя / день (слева направо).
    Это ТЕ ЖЕ две верхние полоски, что в приложении U613 Stat: верхняя — слова, нижняя — все занятия. Цвета те же (их считает телефон, приложение LuvU613),
    размеры те же: высота 36, сегменты 125 + 125 + 124 с зазорами 3, расстояние между полосками 18; нет данных — серый 3A3A3A, как в приложении.
    Циферблат берёт цвета НЕ у телефона, а у приложения U613 Stat: приложение (версия 1.0.6 и новее) при каждом обновлении кладёт цвета двух верхних
    полосок в общее хранилище Zepp OS (API_LEVEL 3.0), циферблат читает их оттуда по номеру приложения 1061613 (STAT_APP_ID в shared/top.js).
    Читает при запуске, при каждом включении экрана и раз в 5 секунд, пока экран включён (REFRESH_MS в watchface/index.js).
    Цвета обновляет само приложение U613 Stat, пока оно открыто (при открытии и раз в минуту): чтобы полоски на циферблате обновились,
    откройте приложение кнопкой 📊 и вернитесь. Пока приложение ни разу не записывало цвета — полоски серые.
    Если общего хранилища на часах нет совсем (не открывается ни одно из двух мест), под полосками появляется красная надпись «нет общего хранилища».
    Верхний край верхней полоски (y = 48) — это «верхний край экрана», его не двигать.
  Под ними — четыре кнопки 2 x 2:
      📊 🧩
      🍀 🥗
    📊 открывает приложение «U613 Stat» (appId 1061613), 🧩 — приложение «Задачи 2» (appId 1061365). 🍀 и 🥗 пока ЗАГЛУШКИ, ничего не открывают.
    Кнопки 🩸 больше нет: приложение «Таймер» запускается функциональной клавишей телефона.
    Чтобы кнопки сработали, оба приложения должны быть установлены на часах (U613 Stat 1.0.6 и «Задачи 2» 1.0.0 или новее).
    Для следующих приложений в watchface/index.js в массиве ACTIONS вместо nothing ставится () => openApp(<appId>, 'page/index').
Приложение «Таймер» и LuvU613 (телефон) этот проект не трогает и не меняет.
Нужны: U613 Stat 1.0.9 (для нажатия на полоски; для одного только чтения цветов хватает 1.0.6, кроме 1.0.8 — в ней запись цветов пропала) и «Задачи 2» 1.0.0 на часах; приложение U613 Stat нужно открыть хотя бы раз после установки 1.0.6.

КАК УСТАНОВИТЬ (так же, как приложение часов)
1. Создайте НОВЫЙ репозиторий на GitHub и загрузите в него ВСЁ из этой папки (Add file -> Upload files). Скрытых папок в архиве нет.
   Файл сборки: Add file -> Create new file, имя .github/workflows/build.yml, внутрь текст из файла build.yml.
2. Settings -> Pages: включите публикацию из ветки gh-pages (как делали раньше). Вкладка Actions: дождаться зелёной галочки
   (если первый запуск прошёл до включения Pages — запустите ещё раз: Actions -> Run workflow).
3. QR-код "square-432x514" -> в Zepp: Профиль -> часы -> Режим разработчика -> сканировать.
4. Циферблат появится в списке циферблатов часов (долгое нажатие на текущий циферблат -> листать в конец списка) —
   выберите его.

ГДЕ ЧТО МЕНЯТЬ
shared/layout.js:
  AREA_X, AREA_W      — горизонтальная полоса, в которой стоят полоски и кнопки (8 и 380: та же сетка, что на главном экране приложения «Таймер»).
                        Если на циферблате всё смещено — меняйте AREA_X (центр экрана для 432 px: AREA_X = 26).
  STRIP_TOP, STRIP_H, STRIP_GAP — где стоит верхняя полоска (48, не двигать), высота полоски (36) и расстояние между ними (18).
  BTN_W, BTN_H, BTN_ROW_GAP, BTN_TOP_GAP — размер кнопки, т.е. области нажатия и файла картинки (190 x 150), зазор между рядами (12), отступ от полосок до первого ряда кнопок (30).
  SEG_GAP             — чёрный зазор между сегментами (3). 0 — сплошная полоска, как на телефоне.
shared/colors.js       — серый «нет данных» (GRAY) и проверка списка из шести цветов.
shared/top.js          — чтение цветов из общего хранилища: STAT_APP_ID (номер приложения U613 Stat), SCOPE и FILE (имена, как в приложении).
watchface/index.js     — REFRESH_MS (как часто перечитывать), QUICK_URL / FULL_URL / REPEAT_MS (нажатие на полоски), TASKS_APP_ID и ACTIONS (что делают кнопки; 🍀 и 🥗 пока заглушки).

ТЕСТЫ (необязательно): npm test — проверяют цвета, раскладку, чтение общего хранилища и прогон циферблата на заглушках API часов.
